# Provenance of `db/`

These files are an *essential set* of Costas arrays — one representative per
orbit of the dihedral group D4 acting on the square — for orders 2 through 100.

**The instance data in this directory is third-party material.** It was not
generated by this repository. The set matches, in structure and content, a
publicly published Costas array database, believed to be James K. Beard's
*"Costas arrays and enumeration to order 1030"*
(<https://jameskbeard.com/Files.html>), distributed under
**CC BY 4.0** — redistribution is permitted, conditional on attribution.
Files were renamed and the set reduced to orbit representatives.

> only.** The data in this directory is governed by its own upstream licence.

## What this repository verifies independently

`costas_generate.py` is an independent implementation, written from the
published mathematics and depending on nothing external. It serves two
purposes: it regenerates part of this data from first principles, and it
checks all of it.

`tests/test_db_integrity.py` re-derives the Costas property for every array
here on every CI run. As of the last run that is **9,217 arrays across 82
orders, all valid**, plus 18 orders correctly recorded as having no known
Costas array (32, 33, 43, 48, 49, 54, 63, 73, 74, 83, 84, 85, 89, 90, 91, 92,
93, 97).

## Regeneration coverage, measured honestly

`costas_generate.py` reproduces this database **completely for orders 2–7** —
that range is a full exhaustive enumeration, and the generator's independent
search returns exactly the same orbits.

For orders 8 and above it currently reproduces a **subset**. The generator
implements exhaustive search, the Welch construction (W1 and two trimmed
variants) and the Golomb/Lempel construction G2 over GF(p^k). The published
database additionally draws on the wider Golomb–Taylor variant family (G3, G4,
G5, T4 and others) and on orders that no known algebraic construction reaches
at all — order 19, for example, has two known arrays and no construction of
that exact order.

Closing that gap means implementing the full variant taxonomy. Until then this
file, not a silent assumption, is what stands between the code and a claim it
cannot support.

```bash
python3 costas_generate.py --max-order 100        # regenerate what it can
python3 -m unittest tests.test_db_integrity       # verify everything present
```
